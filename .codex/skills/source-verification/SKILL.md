# Skill: Source Verification
Description: Guidelines for evaluating credibility, detecting official sources, and verifying URLs before asserting claims.

## Guidelines
1. Call `verify_source` on primary candidate URLs to confirm domain authenticity and detect conflicts.
2. Official portal URLs must be confirmed by checking domain reputation and protocol.
3. If search sources contradict each other, explicitly note the discrepancy in the observation and reasoning rather than hiding it.
4. Do not cite a URL or claim a tool ran unless a real tool call was executed and succeeded.
