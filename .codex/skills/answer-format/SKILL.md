# Skill: Answer Formatting
Description: Standard formatting guidelines for final synthesis and user communication in Cerlesse.

## Guidelines
1. Synthesize user-facing answers with clear, authoritative Markdown.
2. Direct, objective language: Avoid fluff, hype, or redundant conversational fillers.
3. Every factual claim should cite the corresponding source numbers `[1]`, `[2]` matching the retrieved and verified sources.
4. Structure complex queries with clear sections: Summary, Core Findings, Actionable Steps, and Source References.
5. All interactive UI elements must be expressed as prepared widgets, never inline script or HTML embeds.
