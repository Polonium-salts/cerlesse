# Skill: Answer Formatting
Description: Adaptive formatting guidelines for final synthesis and user communication in Cerlesse.

## Guidelines
1. Direct answer first: Start with the direct answer in the first sentence or two without boilerplate preambles or generic titles.
2. Adapt shape to question type:
   - Simple fact / definition / yes-no: 1–3 concise sentences, no artificial headers or lists.
   - How-to / troubleshooting: Ordered steps with code/commands directly from evidence.
   - Comparison: Use prose or tables naturally depending on entities and attributes.
   - News / events: Chronological paragraphs with dates.
   - Broad research: Meaningful topic-specific headers (never generic placeholders like "背景与原理解析").
3. Strict numeric citations: Every factual claim must cite source numbers `[1]`, `[2]` matching verified sources.
4. Prose is default: Only use headers, lists, or tables when they make the specific answer clearer.
5. Interactive UI elements are expressed via prepared widgets; the main answer summarizes without redundant table cloning.
